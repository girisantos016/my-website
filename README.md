# Santosh Giri — Academic Website

Static HTML/CSS/JavaScript website for GitHub Pages.

## Edit content
- Main profile, research, projects, publications, teaching and links: `index.html`
- Styling: `assets/css/style.css`
- Interactions/animations: `assets/js/script.js`

## Replace files
- Profile photo: replace `assets/images/profile-placeholder.svg` with a verified photo and update the `<img>` path in `index.html`.
- CV: add your verified CV as `assets/documents/Santosh-Giri-CV.pdf`.
- Add verified DOI/publisher/social URLs directly in `index.html`; no unverified links are included.

## Publications/projects
Add or edit the cards under `#publications` and `#projects` in `index.html`. Keep bibliographic details verified before publishing.

## Deploy to GitHub Pages
Create a GitHub repository, upload the contents of this folder to the repository root, then enable **Settings → Pages → Deploy from branch → main / root**.
